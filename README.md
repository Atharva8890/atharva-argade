# Atharva Argade

A lightweight personal website built with plain HTML, CSS, and JavaScript. It
is designed to work on any static hosting service, including GitHub Pages.

## Preview locally

Open `index.html` directly in a browser, or serve the folder with a simple local
server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Update copy and links in `index.html`.
- Adjust colors, layout, and responsive styles in `styles.css`.
- Extend small interactions in `script.js`.
